# StreamPlanner · calendario

Aquí vive `turnos.ics`, el calendario de turnos que publica la app
[StreamPlanner](https://felipeanali.github.io/mensajito/streamplanner/).
La app lo actualiza sola con la API de GitHub; el iPhone está suscrito a:

`webcal://raw.githubusercontent.com/FelipeAnali/streamplanner/main/turnos.ics`

No edites `turnos.ics` a mano: la app lo reemplaza en cada subida.
